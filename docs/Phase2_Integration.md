## 統合した内容

- CSV・TSV・XLSXを共通のファイルタブで開きます。同一ファイルの再指定は既存タブへ移動します。
- XLSXのシート切替・保護付きセル編集・範囲貼付け・Undo/Redo・検索・文字列一括置換・選択シートのCSV出力・条件付きシート操作をタブ内に接続しました。
- ファイルごとにXLSXブック、選択シート、履歴、保存先、外部変更確認用の指紋を持ちます。
- 上部の保存・別名保存・タブを閉じる・Ctrl+S・Ctrl+Z・Ctrl+Shift+Zは現在のファイルを対象にします。
- CSV専用の行列操作・見出し・文字コード再読込は、XLSXタブでは無効になります。XLSXの検索・置換はタブ内の操作欄を使います。CSV検索画面はXLSXへ移動すると閉じます。
- 最近使ったファイル、ウィンドウ配置、サブ画面配置、ログ、バックアップ設定を既存の本体機構に接続しました。XLSX側と上部のバックアップチェックは同じ設定を使います。
- 未保存のあるタブを閉じる／アプリを終了する場合は保存・破棄・キャンセルを選べます。全タブの確認が終わるまでタブを削除しません。
- 別タブのファイルを別名保存・バックアップ・CSV出力で上書きしないようにします。CSVからXLSXへの変換保存は未対応で、CSVの保存先にExcel形式の拡張子を指定すると中止します。
- openpyxl 3.1.5／et-xmlfile 2.0.0を正式な依存関係へ追加し、ビルド時のVersion検査・ライセンス収集・ビルド情報も更新しました。生成XLSXの配布物混入を拒否します。

## 継続する制限

- XLSXは現在ブック全体10万セルまで、各シート先頭1000行×50列まで表示します。検索・CSV出力はブック／シートの全体を対象にします。
- XLSXはRGB背景・文字色、dev4で追加した基本的な数値・日時書式と左右中央配置の表示に対応します。太字等・結合の見た目・縦配置の再現は未対応です。保存時は検証済みの基本書式・結合を保持します。
- dev3からXLSX内の列幅を表示し、変更した幅をブックに保存します。XLSXの列幅はJSONには保存しません。
- dev12でXLSXの直接入力に対応しました。既存の編集ボタンと範囲貼付けも利用できます。型維持・保護を通して表示範囲内へ入力し、自動拡張は行いません。行列の挿入削除・末尾追加は検証済みの条件内で利用します。
- シート追加は末尾のみ。数式を含むブックのシート削除・名前変更は参照保護のため禁止します。
- dev6から1件置換にも対応します。置換は通常の文字列セルのみ。数式・結合・エラー・数値・日時・真偽値を除外します。
- 数式は計算せず文字列として保持します。保存により計算結果キャッシュが失われる場合があります。CSVの数式出力は初期中止で、「数式文字列を出力」を選んだ場合のみ許可します。
- 未対応の部品・XML機能・テーマ等を検出するとXLSXを読み取り専用にします。すべてのExcel機能を保持できる判定ではありません。読み取り専用でも検索と、解析可能な値のCSV出力は可能です。
- XLSX別名保存とCSV出力は新規ファイルのみで、ハードリンク対応の保存先が必要です。上書き保存は一時保存・再読込比較・バックアップ・指紋比較を経て置換します。外部アプリの同時変更や電源断に完全な耐性を保証するものではありません。

## XLSX列幅（dev3）：今回の確認1～6

自動テスト465件成功。仮想画面でも幅変更・Undo/Redo・XLSX保存／再読込・JSONに列幅が追加されないことを確認しました。

**XLSXの列幅はXLSX内に保存します。JSONへは保存しません。**
CSVの表示列幅は、既存のJSONによる管理を継続します。
XLSXでは各シートの列定義を読み、列幅の変更を未保存の編集として扱います。
保存前の変更はファイルへ反映せず、保存に成功すると次回の読込でも復元されます。

- 列の境界をドラッグして幅を変更します。1回の変更をUndo/Redoの対象にします。
- 他シート・他ファイルへ移動して戻っても、編集中の幅を保持します。
- 保存時はXLSX内の列幅定義を更新し、既存の再読込比較・バックアップ・外部変更検出を使用します。
- 表示しただけの列や、変更していない列の元の幅値は書き換えません。画面描画による自動履歴も作りません。
- 複数列をまとめた列定義は必要な部分だけ分割し、隣接列の幅・書式・グループ情報を維持します。
- 読み取り専用ブックでは列幅変更を禁止します。非表示・幅0・重複定義の列の幅変更も中止します。
- 画面上の最小表示幅は20ピクセル、変更可能な最大値はExcel列幅255相当です。範囲外の元の値は未変更なら保持します。
- Excel列幅とピクセル幅は、Normalスタイルの数字フォント幅を基に変換します。フォントの代替やDPI差により、Excelと描画が完全一致するとは限りません。

参考：<https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.spreadsheet.column?view=openxml-3.0.1>

1. **初期表示と無変更**：basic.xlsxを開き、幅を指定済みのA列が他列より広く表示されることを確認します。開くだけでは未保存=なし、Undo無効であることを確認します。
2. **幅変更とUndo/Redo**：A列の境界をドラッグして広げ、未保存=ありとUndo有効を確認します。Undoで元の幅と未保存=なしへ戻り、Redoで変更後の幅に戻ることを確認します。
3. **シート・ファイル切替**：売上A列の幅を変更→補足へ移動して補足A列も別の幅へ変更→売上へ戻ります。それぞれの幅が残ることを確認します。CSVなど別ファイルへ切り替えて戻っても幅が残ることを確認します。
4. **XLSXへの保存と再起動**：未使用のファイル名へ別名保存します。保存後は未保存=なしになることを確認します。アプリを終了・再起動して保存したXLSXを開き、シートごとの幅が復元されることを確認します。Excel等があれば、同じXLSXでも幅の変更が反映されていることを確認します。
5. **保存後の履歴と失敗**：保存直後にUndoすると未保存=あり、Redoでなしになることを確認します。検証用コピーをファイルロックして幅を変更・上書き保存するとエラーになり、編集中の幅と履歴が残ることを確認します。ロック手順は前段の保存確認と同じです。
6. **読み取り専用とCSV**：validation_readonly.xlsxでは境界ドラッグで列幅を変更できないことを確認します。CSVでは従来の表示列幅の記憶が動き、列幅変更だけでCSVが未保存にならないことを確認します。

## 表示書式（dev4）：今回の確認1～6

自動テスト505件成功。仮想画面で表示・配置・シート切替・元の値の編集・Undo/Redo・保存を確認しました。
表示のために値や書式を書き換えず、表示しただけでは未保存にも履歴にも入りません。
書式の変更機能は今回追加していません。

| 対象 | 今回対応する表示形式 |
| --- | --- |
| 数値 | `0`、`#,##0`と、小数部の0を1～6桁付けた形式（例：`0.00`、`#,##0.00`） |
| パーセント | 上記の末尾に`%`（例：`0%`、`0.00%`）。元の値0.125を12.50%と表示 |
| 日付 | `yyyy-mm-dd`、`yyyy/mm/dd`、`yyyy/m/d`、`mm-dd-yy` |
| 時刻 | `hh:mm:ss`、`h:mm:ss`、`hh:mm`、`h:mm` |
| 日時 | 対応する日付形式と時刻形式を半角スペース1個で組み合わせた形式 |
| 配置 | 明示されたleft/center/right。標準は文字列・数式が左、数値・日時が右、真偽値・エラーが中央 |

数値の表示丸めは十進数で四捨五入します。Excelの全書式・ロケール・条件付き書式を再現する機能ではありません。
通貨、指数、色付き・条件付きの複数セクション、和文リテラル等は今回の対象外です。
未対応の形式は元の値を表示し、該当セルを選ぶと「表示書式未対応（元の値を表示）」と案内します。
文字列の先頭ゼロ、数式文字列、真偽値は引き続きそのまま表示します。

編集画面には表示文字列ではなく元の値を渡します。パーセントは0.125のような元の数値、
日時はISO形式で入力します。表示と元の値が異なるセルを選ぶと、下部に元の値も表示します。
検索とCSV出力は従来どおり元の値を対象にします。表からの通常のコピーは表示文字列です。
XLSXの保存には元の型と書式を使用します。列幅・Undo/RedoとCSVの既存動作も維持します。
