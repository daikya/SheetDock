# SheetDock 要件定義 v1.0

確定日：2026年10月13日。全38項目。状態：要件確定、技術検証開始。

## 1. 目的と方針

Microsoft ExcelなしでCSV・Excelファイルを閲覧・編集・保存できる、軽量なWindowsデスクトップアプリを開発する。Excelの完全互換ではなく、編集の使いやすさ、既存データの保護、安定性を重視する。

必要な段階で必要なフォルダー、コード、テスト、文書だけを追加する。編集エンジンとGUIを分離し、CSV・Excelの読み書きは個別に扱い、共通化できる編集操作は共通化する。

## 4. 動作・保護の補足

- CSVの先頭ゼロ、日本語、カンマ、引用符、セル内改行を保持する。保存後の意味的な一致とバイト単位の一致を区別する。
- 文字コードの判定が曖昧な場合は利用者が選択する。混在改行の正規化ルールは検証段階で定める。
- 保存前の検証、保存先と同じフォルダーの一時ファイルへの書込、書込結果の検証、元ファイルの置換を行い、設定に応じてバックアップする。
- 保存失敗時は元ファイルと編集中のデータを保護し、エラーを表示する。電源断・ディスク障害への完全な耐性を保証するものではない。
- 外部変更の検出は更新日時・サイズなどを検討する。再読込時は未保存の編集内容を失う前に確認する。多重起動時の保存競合対策も検証する。
- 設定JSONに編集中のCSV・Excelデータは保存しない。ログにはセル内容や個人情報を原則記録しない。
- ファイルタブとは別にExcelのシートタブを設ける。
- 数式は再計算しない。表示する計算結果が古い可能性を区別する。数式・結合セルに影響する行列操作は安全性を検証してから許可する。
- 検索は数式セルを含めるか別途検討する。置換は1件または一括、いずれもUndo対象とする。数式の編集禁止は置換・貼付け・削除にも適用する。
- ExcelからCSVへの出力は元XLSXを変更しない。CSVは数式・書式・複数シートを保持しないため、数式セルの出力方法は検証時に定める。
- openpyxlですべてのExcel機能を完全保持できるとは想定しない。未対応機能の検出範囲を定め、判定できない場合も安全側に倒す。

## 6. 技術検証

1. tksheet：セル編集、範囲選択、Excel相互コピー、行列操作、Undo/Redo、検索・置換、GUIと編集モデルの同期。
2. CSV：文字コード・BOM・改行・引用符・区切り文字、保存精度、保存失敗時の保護。
3. 編集モデル：共通操作とExcelの型・数式・書式の保持を両立。
4. Excel：保持できない機能の検出と読み取り専用判定、構造変更の安全性。
5. 大容量CSV：メモリ使用量・画面応答性を実測して警告基準を決定。

## 7. Phase 1完成条件

- CSVを開き、編集して保存できる。
- 先頭ゼロ、日本語、セル内改行が保持される。
- 複数ファイルをタブで操作できる。
- Excelとの範囲コピー・貼り付けができる。
- 行列操作と置換をUndo/Redoできる。
- 保存失敗時に元ファイルと編集中データを保護できる。
- pytestがすべて成功する。
- Windows実環境でGUI操作確認が完了する。
