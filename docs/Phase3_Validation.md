## 最初の検証範囲

CSVの独立CLIプローブから始めます。本体の機能・Version・既定のテスト対象は変更しません。XLSXの行移動は数式参照・結合・書式・行高等に関わるため、CSVと分けて検証します。

| 操作 | 今回の仕様 |
| --- | --- |
| 並べ替え | 指定した1列で本文の行全体を移動。見出しありなら先頭行を除外 |
| 比較方法 | 文字列順／明示した数値順、昇順／降順。同値の順序を保持、空セル・欠けたセルは常に最後 |
| 数値順 | 比較にDecimalを使い、元の文字列・先頭ゼロは維持。小数・符号・指数を許可。桁区切り・非数値・非有限値は拒否 |
| 履歴 | 並べ替え1回をUndo/Redo1回とする。行高は行と一緒に移動。列幅は維持。変化なしでは履歴を追加しない |
| フィルター | 1列に部分一致・完全一致・空・空以外の条件。大文字小文字を区別。データ行番号の表示だけを絞り、見出しは表示 |
| フィルターの影響 | 元データ・未保存状態・Undo/Redo履歴を変更しない。解除で全行表示。結果0件なら見出しだけ（見出しなしなら0行） |
| 保存 | フィルター解除中のみ全行を新規名へ保存。元の文字コード・BOM・改行・区切りを維持し、再読込比較。既存出力は上書きしない |

この段階ではフィルター中の並べ替えと保存を拒否し、GUI編集・削除・コピーにはまだ接続しません。隠れた行を削除したり、保存対象から落としたりしないため、GUI接続時に表示行とデータ行の対応を検証します。

文字列順はPythonのUnicode順です。自然順・五十音順・複数列の優先順・数値範囲・複数条件・フィルター結果だけの出力は今回含めません。これらを追加要件として確定したものではありません。

- 履歴でシート構成が変わった場合は条件・見出し指定をリセットします。行列範囲が変わった場合も条件を解除し、消えた列への条件を残しません。通常のセル編集・並べ替え・幅や高さの履歴では条件を保って再評価します。
- 上書き・別名保存は常に非表示行・他シートを含む全ブック、CSV出力は非表示行を含む選択シート全行です。本文0件でも保持します。保存先競合・外部変更・バックアップ・失敗時の編集保持は既存の保存経路を使います。
- 条件はファイル・シート別のメモリ上だけに保持します。保存後は条件を維持し、再読込・再起動では解除します。XLSXや設定JSONに書き込みません。
